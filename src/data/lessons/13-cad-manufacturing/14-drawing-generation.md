## From 3D Model to 2D Print

A machinist ultimately works from a 2D drawing — the blueprint reading module covered how to read one, and this lesson covers how one gets made. Modern CAD software generates a 2D drawing directly **from** the 3D model, rather than requiring the drawing to be created as an independent, separately drawn document. This link is the whole point: a change to the 3D model propagates automatically to every view and dimension on the drawing that depends on it, rather than leaving the drawing to silently fall out of sync with the actual part.

:::key-concept
A drawing generated from a model isn't a picture of the model taken once and then edited independently — it stays a live, linked representation. This is the same parametric principle behind every feature covered in this module, extended from the 3D model itself to the 2D documentation describing it.
:::

## Standard Orthographic Views

A drawing typically starts with a **base view** — usually the model's front view, chosen to show the part's most representative profile — and additional standard views (top, side, isometric) are projected directly from that base view, staying aligned and to scale automatically. This mirrors the orthographic projection principles covered in the blueprint reading module, just generated by software instead of drafted by hand.

## Section and Detail Views

- A **section view** cuts through the model along a specified plane, revealing internal geometry that wouldn't otherwise be visible from any external viewing angle — essential for showing an internal bore, a counterbore, or a wall thickness that a standard outside view can't convey.
- A **detail view** magnifies a small region of an existing view, useful for a small feature (a fine thread, a small fillet, a tight tolerance zone) that would be difficult to dimension clearly at the drawing's overall scale.

Both are generated from, and stay linked to, the same underlying 3D model as every other view on the drawing — a section view updates automatically if the model's internal geometry changes, the same as any other view.

## Dimensions Pulled from the Model

Dimensions placed on a generated drawing are typically pulled **directly from the model's actual geometry**, rather than measured and typed in independently by the drafter. This has a real accuracy advantage: a dimension pulled from the model is guaranteed to match the model's actual geometry, where a dimension manually measured and typed onto an independently-drawn drawing carries the risk of a typo or a measurement error that has nothing to do with the model itself.

:::warning
When a model changes after a drawing has already been created, dimensions pulled from the model update automatically to the new value — but this also means a drawing left open with an outdated view or an unrefreshed sheet can display stale information until the drawing is actually reopened or regenerated. Always confirm a drawing reflects the current model state before treating it as final, especially after a recent design change.
:::

## Self-Check Questions

**1. Why does a drawing generated from a 3D model stay accurate as the model changes, where an independently drawn drawing wouldn't?**

<details>
<summary>Show Answer</summary>

The drawing's views and dimensions remain linked to the model, so a change to the model propagates automatically to the drawing, rather than the drawing being a static picture that has to be manually updated.
</details>

**2. How are the top and side views typically generated once a base view is established?**

<details>
<summary>Show Answer</summary>

They're projected directly from the base view, staying aligned and to scale automatically, rather than being independently drawn — mirroring standard orthographic projection principles.
</details>

**3. What does a section view show that a standard external view can't?**

<details>
<summary>Show Answer</summary>

Internal geometry — such as an internal bore, counterbore, or wall thickness — by cutting through the model along a specified plane, revealing what wouldn't be visible from any external viewing angle.
</details>

**4. Why is a dimension pulled directly from the model more reliable than one manually measured and typed onto an independently-drawn drawing?**

<details>
<summary>Show Answer</summary>

A model-pulled dimension is guaranteed to match the model's actual geometry, while a manually typed dimension carries the risk of a typo or measurement error unrelated to the model itself.
</details>

**5. Why should a drawing be confirmed as reflecting the current model state before being treated as final, especially after a recent design change?**

<details>
<summary>Show Answer</summary>

A drawing sheet left open with an unrefreshed view can display stale information from before the change until it's actually reopened or regenerated, even though the underlying link to the model exists.
</details>
