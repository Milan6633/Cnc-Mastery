Quick reference for the most common CNC codes. Primarily Fanuc/Haas compatible.

Controller differences

While the core G-code set is similar across controls, there are important differences:

  • Fanuc — the de facto standard; most machines use a Fanuc variant. Type I and Type II cutter comp, G70/G71/G72/G73 for turning, G76 threading.
  • Haas — Fanuc-like but with simplifications: G70 bolt circle, G71 bolt arc, G72/G73 pattern repeats differ; G84 rigid tap is default; G103 block restrict.
  • Siemens — ShopTurn/Mill uses DIN 66025; cycles are called with CYCLE81, CYCLE83, etc. rather than G81/G83. Siemens also supports high-level language (Sinumerik).
  • Mazak — Mazatrol conversational is primary; G-code mode (EIA/ISO) is also available but differs in syntax.
  • Okuma — uses OSP (Okuma Special Parameters) control; code set is similar to Fanuc but with different alarm codes and some unique functions.
